## 边界

- JourneyMap API 仅编译时使用，不打入 DuskRain JAR；运行时由 JourneyMap 自带 API 提供。
- Sound Physics 对应筛选结果为 Beta，因此为可选；FastSuite 及递归依赖 Placebo 也为可选，避免未经收益验证即默认更改配方缓存。
- 3D Skin Layers 与 Entity Culling 受 tr7zw Protective License 约束，安装脚本指向官方文件。
- 原有渲染栈继续锁定版本；新的功能组件不引入第二套修仙、经济、领地或商店系统。
- 第三方源码、各自完整许可证链接、版本 ID、发布日期、SHA-1/SHA-256/SHA-512 均保存在锁文件中。
- DuskRain 原创资源按仓库自身许可提供。
