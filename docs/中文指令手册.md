# DuskRain · 烟雨仙途

群号 **205255670**。版本 Minecraft Java 1.20.1 / Forge 47.4.10 / Java 17。当前为重制体验版。

## 玩家入口

按 **G** 打开菜单；**Z / X / C** 对应三个主动技能。右键具名村民或登记柜台打开对应服务。普通玩家无需 OP。

| 指令 | 用途 |
|---|---|
| `/dr menu` | 主菜单 |
| `/dr spawn` | 回城，5 秒引导；移动或受伤取消 |
| `/dr warp` | 分区传送菜单 |
| `/dr profile` | 修炼属性与境界 |
| `/dr cultivate choose 1` | 选择剑修；2 为术修，3 为体修 |
| `/dr cultivate sit` | 开始/停止静坐调息 |
| `/dr cultivate breakthrough` | 校验修为并尝试突破 |
| `/dr skills` | 技能说明、解锁和施放 |
| `/dr skills cast 0` | 施放第 1 技能；另外两槽为 1、2 |
| `/dr quests` | 主线任务 |
| `/dr daily` | 每日委托与签到菜单 |
| `/dr daily sign` | 签到，每个北京时间自然日一次 |
| `/dr balance` | 灵石余额 |
| `/dr shop` | 材料商店 |
| `/dr shop view alchemy` | 丹坊；器阁分类为 forge |
| `/dr shop buy bread 3` | 购买 3 份商品；商品编号与份量见商店配置 |
| `/dr shop sell bread 3` | 出售白名单物品，受每日回收上限限制 |
| `/dr claim` | 住宅菜单 |
| `/dr claim add` | 认领当前区块，默认最多 9 个并保持相邻 |
| `/dr claim trust 玩家名` | 授权在线成员；untrust 解除授权 |
| `/dr home set` | 在自己领地设置家 |
| `/dr home` | 引导回家 |
| `/dr party invite 玩家名` | 邀请组队 |
| `/dr party accept` | 接受邀请 |
| `/dr party leave` | 离开队伍 |
| `/dr trial` | 试炼菜单 |
| `/dr trial enter 1` | 进入低阶试炼；2 中阶，3 高阶 |
| `/dr trial leave` | 放弃本轮试炼并退出 |
| `/dr arena` | 切换擂台对战意愿，双方同意且都在擂台内才可对战 |
| `/dr sidebar toggle` | 隐藏/显示右侧信息栏 |
| `/dr sidebar scale 0.85` | 信息栏缩放，允许 0.65–1.5 |

剑修实际普攻距离加成需要持有合规剑或对应绑定法器。体修提供移动、跳跃和生存加成；术修提高灵力与恢复效率。安全区与擂台规则同样约束主动技能。

主城禁止普通玩家拆建。野外住宅保护拆建和容器，但领地内仍允许 PVP。野外死亡保留已装备护甲、绑定法器、境界与灵石，其他背包物品正常掉落。满背包的试炼奖励会暂存，腾出空间后自动补发。

## 管理员

`/dr admin` 默认要求 **OP 等级 3**。

| 指令 | 用途 |
|---|---|
| `/dr admin maintenance` | 为当前管理员切换维护绕过；退出登录后清除 |
| `/dr admin reload` | 重读并校验 rules.json |
| `/dr admin stage 玩家名 0` | 修正阶段，0–20；不会自动领取任务奖励 |
| `/dr admin money 玩家名 100` | 设置灵石余额 |
| `/dr admin reset_school 玩家名` | 清除流派选择与加成，重新选择 |
| `/dr admin repair 玩家名` | 尝试补发保存中的装备/奖励 |
| `/dr admin audit` | 内容与维度定义检查 |
| `/dr admin walk_audit` | 实际区块入口、楼梯和道路碰撞检查，输出 JSON |
| `/dr admin pregen` | 预生成 1024×1024 主城范围 |

## 可观看建造

在独立 `duskrain:construction` 维度演示。不会清空正式主城。摄影机命令会将当前玩家置于旁观模式。

```text
/dr build start palace
/dr build start city
/dr build pause
/dr build resume
/dr build speed 600
/dr build camera palace
/dr build camera aerial
/dr build camera orbit
/dr build camera off
```

停止自动镜头后仍为旁观模式，管理员可用原版 `/gamemode survival` 恢复。`/dr build record true` / `false` 是现有帧序列录制开关，当前采样为每两客户端 tick 一帧。最终 1080p/30fps 视频尚未交付。

## 配置与排查

- `config/duskrain/rules.json`：价格、回收上限、境界修为、流派参数、任务和试炼时限。修改前备份，再运行 reload。
- 服务端和客户端必须安装同一版 DuskRain 2.1.0-preview 与 GeckoLib 4.8.4；协议号为 7。
- Embeddium 和 Oculus 仅安装到客户端。
- 发现显示空白的新版主城告示牌，可以右键触发同步；自动恢复只处理能对应到主城设计坐标的空白牌，保留已有非空自定义文字。
- 最新进度、备份位置、实际验证和未完成项目见《本轮更新与验证》。


## 水墨界面与场所交互更新

F8 切换行旅 HUD；G → 显示设置选择侧栏缩放与光影档。商店请到材料铺、丹坊、器阁右键对应村民；拜师与突破在问道书院办理，任务奖励在任务殿交付，试炼从问劫云台开启。指令仍保留，服务端同时检查所在场所。

管理控制台可用 `dr admin route_audit` 检查全路网和桥头转弯空间，`dr admin site_audit` 检查真实照明与道路基础。


## 新手与衣装

首次入服到烟雨迎客台，获得58页《入世手册》、听雨布衣四件套、长明探索火把与归云罗盘。点击“启程”进入主城；已有玩家不会重置或重复领取礼包。

- `/dr start`：首次启程；之后用 `/dr spawn` 回城。
- `/dr guide`：丢失手册时补领；背包满时暂存待补发。
- 归云罗盘：潜行+右键切换主城/自己的住宅家点，右键查看坐标；跨维度时需先传送。
- 长明探索火把：放在主手或副手时通过客户端动态光源照明，等级15；普通火把等级14。
- 器阁提供二十一阶段法衣，每套发冠、上衣、下裳、云履。服务端检查穿戴境界。

## 住宅与玩家商铺

`/dr claim list` 查看区块，`/dr claim members` 查看成员，`/dr claim border` 显示边界。`trust` / `untrust` 支持已知玩家名与 UUID。先站在自家领地安全地面 `/dr home set`，之后 `/dr home` 引导回家。

`/dr warp stalls` 到烟雨商坊。右键小屋柜台办理。默认2500灵石购铺，每人1间，12间可用。

- `/dr stalls buy <0到11>`：在对应柜台附近购买。
- `/dr stalls`：打开27格陈列界面，选背包实物，填写单价和数量；每种库存最多4096件，支持补货、调价和部分取回。
- `/dr stalls sell <整组总价> <数量>`：兼容旧命令，托管最多64件主手物品，按整组价格建立旧批次；与新商品共用27个位置。
- `/dr stalls purchase <商品UUID>`：购买旧批次整组。新商品在陈列界面选择购买数量并确认总价。
- `/dr stalls take <商品UUID>`：店主取回旧批次未售货品。

客户端提供上架价格和数量表单；所有扣款、库存和卖家收入由服务器校验。

## 主城福泽和轻量HUD

主城自动补满饱食与饱和，移速+40%，跳跃增强；体修叠加职业加成为+65%。落地起跳后，松开空格再按可二段跳；每次落地补充一次。离开主城清除主城加成。
F9切换卷轴/半透明HUD，F8隐藏左上角信息。侧栏仍保留全部字段。


## 护甲商店与 HUD 更新（指南 15）

器阁底部“上页 / 下页”用于切换目录，滚轮用于查看本页其余商品。顶部筛选法器 / 法衣、境界和部位。Z / X / C 的状态在右下角，F9 同时切换左上信息、侧栏和技能条的卷轴 / 半透明样式。背包、副手、末影箱中的旧指南自动升级；缺失时用 `/dr guide` 补领。

## V14 新增功能（协议7）

铭灵轩旁 `/dr enchant` 打开指定附魔页面；`/dr flight` 查看御剑与体验余时，`/dr flight toggle` 起剑或缓降；`/dr title` 查看并切换名下头衔。R、空格、Shift分别用于起落、上升、下降，落地后恢复普通移动。

`/dr guild rename 合欢宗` 支持中文宗名；创建与转让要求至少渡劫后期。`/dr stalls` 必须在小集货柜旁，可管理27种商品及部分数量；旧整组寄售价格保留。

84件法衣、21件法器、登神三阶段及附魔具体费用见 [V14功能说明](V14-功能说明.md)。完整游戏说明书58页，使用 `/dr guide` 补领。
