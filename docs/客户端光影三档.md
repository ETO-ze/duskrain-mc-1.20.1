# DuskRain · 客户端光影三档

Minecraft Java 1.20.1 / Forge 47.4.10 / Java 17。三档均使用内置的 **Complementary Reimagined r5.3**，不需要额外购买光影或纹理。

## 三档设计

| 档位 | 参考显卡 | 建议起始分辨率 | 视距 | 阴影距离 | 主要差异 |
|---|---|---|---:|---:|---|
| 轻岚 · 流畅 | 桌面 RTX 2060 | 1920×1080 | 10 区块 | 128 格 | Medium 基础，水面反射、基础体积光，较低材质反射 |
| 烟雨 · 均衡 | 桌面 RTX 4060 | 1920×1080 | 14 区块 | 192 格 | High 基础，更细致阴影、体积光和完整材质反射 |
| 云阙 · 精致 | 桌面 RTX 5070 | 2560×1440 | 20 区块 | 224 格 | Very High 基础，高质量云层与细节、8×各向异性、256 彩色光照范围 |

这些是按目标硬件设计的起始配置，**不是三张显卡的帧率保证**。笔记本同名显卡、CPU、显存、后台程序、多人活动与录制都会影响实际表现。遇到卡顿可以降低一档；分辨率由玩家在游戏或启动器中选择，切档不强制改变窗口。

共同设置：模拟距离 6、帧率上限 120、TAA 抗锯齿、克制泛光、动态草木；关闭动态模糊、景深与远处灯光散景，保证战斗目标和导视清楚。保留玩家原有垂直同步、按键、FOV、GUI 缩放及无关光影选项。服务端视距设置可能进一步限制客户端可见范围。

## 游戏内一键切换

1. 按 **G → 显示设置**，进入「烟雨画境」。
2. 点击任一档位，等待光影编译完成；切换中可能短暂停顿。
3. **关闭光影**可使用原版渲染；**恢复上次设置**会恢复最近一次切换前的备份。
4. **侧栏设置**连接原有侧栏缩放与隐藏菜单。
5. **记录 30 秒帧率**：关闭菜单后预热 10 秒，再记录 30 秒，结果保存到游戏目录的 `duskrain-benchmarks`。测试时保持同一场景、分辨率和天气，以便比较。

三档参数从同一个 `visual-profiles.json` 生成，游戏界面与安装脚本一致。更换档位只影响本机画质，不改变技能、境界或服务器保护规则。

## 安装与离线切换

通过启动器安装游戏和 Forge 后，把交付包 `client` 中的 **mods、shaderpacks、resourcepacks、config、options.txt、profiles、apply-profile.ps1** 复制到该独立实例。新客户端默认内置「轻岚」档，适配未知硬件时从较低负载开始。

已有实例建议先复制 mods / shaderpacks / resourcepacks，再用脚本合并设置，保留自己的 `options.txt`：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "客户端包\apply-profile.ps1" -Profile rtx4060 -GameDirectory "你的游戏实例目录"
```

可选参数：`rtx2060`、`rtx4060`、`rtx5070`、`off`。旧名称 fluent / standard / recording 分别映射到三张显卡档位；现在 fluent 也启用光影。**离线脚本在游戏关闭时使用**，游戏中用 G 菜单切换。

把三个「画质-RTX*.bat」也复制到游戏实例根目录后，可以双击选择画质。备份位于 `duskrain-visual-backups`，上次备份编号记录在 `config/duskrain-visual-backup.txt`。

客户端组件固定为 Embeddium 0.3.31、Oculus 1.8.0、GeckoLib 4.8.4。Oculus、Embeddium 放在客户端，服务端不需要。不要同时装 Rubidium 或旧 Oculus GeckoLib Compat。

## 原创立体材质与手持照明

内置资源包新增 21 组 64×64 的原创 LabPBR 材质，包括青瓦、砖缝、雕花白玉、木纹和铜饰。每组有颜色、法线/高度、材质反射三张图。屋檐、屋脊、斗拱和灯具另有真实方块模型。

| 档位 | 法线与材质反射 | 视差凹凸 POM |
|---|---|---|
| RTX 2060 | 开启 | 关闭，减轻负载 |
| RTX 4060 | 开启 | 64 级采样，24 格内 |
| RTX 5070 | 开启 | 128 级采样，32 格内 |

POM 用光影模拟表面凹凸，不改变方块碰撞。关闭光影后，原创颜色贴图及屋檐等模型仍可使用。

新增客户端 Sodium/Embeddium Dynamic Lights 和 Sodium Options API，均固定 Forge 1.20.1 的 1.0.10 发布版本。长明探索火把可在副手照亮附近；配置默认 FAST、自身和其他实体照明开启。其方块亮度为 15，普通火把为 14，这是 Minecraft 的最高方块光照等级。动态照明只改变客户端显示，不改变服务器刷怪判定。
