## 性能记录

实际硬件：Intel Core Ultra 7 265K，约16 GB RAM，NVIDIA RTX4060；客户端与集成服务端同机。20个模拟ServerPlayer真实注册到世界及玩家列表，10御剑、10施法，另有真实观察客户端；固定预加载区域，冷却加速，非20名真人或远程网络负载。

首轮1200tick约61.11秒，300次有效施法：TPS19.64，tick P95 20.91ms、最大115.94ms、已用堆约2549MiB。单次尖峰仍存在，不能宣称消除卡顿。

1080p标准档有效重测：约107.42平均FPS，帧P95 14.22ms、最大26.54ms；TPS19.72，tick P95 14.57ms、最大94.74ms。无失焦帧。

720p轻岚档独立一轮：约104.2平均FPS，帧P95 14.26ms、最大35.51ms；server tick P95 11.89ms、最大24.99ms。

1440p高画质档以真实2560×1440全屏执行：约60.16平均FPS，帧P95 24.22ms、最大66.10ms，开启垂直同步；server tick P95 14.54ms、最大48.19ms。三轮均记录1200个服务端tick，客户端预热10秒后测量约30秒，帧统计期间无菜单和失焦。原始按墙钟计算的TPS有短时追赶，汇总按游戏上限20封顶并保留原始值。

三档完整数据见`qa/v14-performance-matrix.json`及对应原始文件，均由本机RTX4060执行，不代表实际2060/5070硬件表现；分辨率、预设和垂直同步共同影响结果，不能当作单一变量的显卡比较。

人工操作改变窗口、传送和菜单的运行无效；观察者生存模式被击杀的一轮也无效。该QA角色已从压测前备份恢复，见`qa/v14-qa-character-restored.json`，工具现强制旁观。

发现并修复的发行问题：新增Mixin补丁补齐Forge成品方法映射；Windows PowerShell安装器修复JSON数组遍历，并使用.NET流式哈希检查。第一次将开发存档载入正式Forge时移除了未使用的GeckoLib开发样例注册；第二次启动无缺失注册错误。交付的玩家物品、建筑均未使用这些样例，已有数据比对通过。
