# DuskRain 2.1.0-preview · 仙侠衣装、登神与合欢宗府邸

Minecraft Java1.20.1 · Forge47.4.10 · Java17 · DuskRain协议7

## 本版内容

- 七境二十一阶：新增登神初、中、后期；84件法衣、21件立体法器、11位服务NPC。
- 铭灵轩与八种专属附魔，保留原版附魔、铁砧和砂轮机制。
- 御剑资格与体验租期、灵力和边界校验、名字下方境界/等级/宗门头衔。
- 中文宗名及合欢宗山水府邸；27格玩家商品商铺，保留旧批次价格及完整物品信息。
- 修复收剑卡视角、铭灵轩悬空基础、宗门池岸和曲桥连接；新手指南更新为58页。

## 下载与安装

- `DuskRain-2.1.0-preview.zip`：客户端、服务端、预生成体验世界、Java17运行时、源码、原创资源、配置和验收文件。
- `duskrain-2.1.0-preview.jar`：单独的配套模组，需匹配Forge及依赖。
- `SHA256SUMS.txt`：下载后校验文件完整性。

客户端通过正常启动器安装MC1.20.1/Forge47.4.10，按包内说明复制模组及资源。服务端运行包根目录 `setup-server.ps1` 获取官方依赖，再运行 `server/start-server.bat`。两端须同步更新至协议7。

本Release属于私有项目，完整ZIP包含当前体验世界及原角色、住宅、商铺数据。它是当前制作成果的可恢复版本；不要覆盖其他正式服的存档。3D Skin Layers提供官方源安装脚本，不直接附带其JAR。游戏本体由正常安装流程获取。
