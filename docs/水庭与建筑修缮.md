# DuskRain 水庭与建筑修缮（2026-09-24）

> 本文保留该阶段的历史测试结果与本机记录路径。2026-09-25 公网迁移及最新交付状态以 [2.2 发行检查](releases/2.2.0-preview.md) 为准。

## 修改范围

- 保留水庭，采用独立 `duskrain:white_jade` / `jade_bricks` 池底、护岸和基座；补回实际存档中缺少的源水。
- 12 间商铺增加墙顶梁板和封口，封闭屋檐下的贯通缝；主城厅堂和宗门楼阁补齐墙顶衔接。
- 白玉栏杆加入原版 fences 标签，恢复直线、转角、连接白玉柱和拆除时的联动；施工结束重算既有栏杆连接。
- 商铺水侧设置独立三格步道，护岸与栏杆外移，水庭方案禁止占用商铺墙体。
- 路灯改为细柱宫灯、六方悬灯、白玉庭灯；新增支座，清除水庭内旧道路、旧灯具残片。
- 41 种中式建筑方块使用独立 ID 和贴图。模组和新版资源包不包含 `assets/minecraft/` 覆盖；玩家自己的其他资源包不修改。
- 施工根据登记的公共建筑、道路、水庭范围进行。容器与告示牌的方块实体不覆盖；书柜等已有陈设不被支撑柱替换。

## 修缮命令（OP 3）

客户端与服务端必须同时使用本轮模组（协议 8）。先保存退出并备份世界，再在维护窗口执行：

```text
/dr admin architecture sample
/dr admin architecture audit
/dr admin architecture all
/dr admin architecture auditbuildings
/dr admin architecture status
```

`sample`：宗务堂、云阁、水庭和南侧商铺区域；`all`：登记的主城建筑和编号 1 的既有宗门府邸。

```text
/dr admin architecture resume
/dr admin architecture rollback
```

栏杆修正版使用 v2 日志；若已有 v1 修缮记录，会核对当前方块仍与此前施工结果一致后再升级，保留 v1 日志。每次 rollback 只回退当前版本日志。

施工逐区块保存原状态和目标状态，先写日志，再写世界；中断后 `resume` 继续。`rollback` 按日志还原，已经被另行修改的方块跳过并记录。日志位于世界目录 `duskrain-architecture-v2/`，应与世界备份一同保留。

只在命令触发时迁移，不在登录时反复刷新。生存世界不参与施工。

## 检查方式

- `audit` 读取真实世界中的白玉池底、源水、栏杆、两格宽上岸石阶、头顶空间和岸上落脚点。
- `auditbuildings` 分区块核对 58 处主城、商铺、景观及宗门建筑的登记结构和周边，报告实际缺块与保留差异；不会为了通过检查而改动世界。
- 自动核对不替代图片审查和玩家游泳、步行体验。实机结果及未通过项目见同目录验收 JSON 和截图索引。

## 保护与限制

本轮源存档备份：`backups/watercourt-20260923-220936/world`。开发验收使用 `mod/run-watercourt-r6` 独立实例。

所有原方块实体跳过，包括有库存的容器、书柜与告示牌。旧道路和旧路灯仅在已批准改造的水庭范围内按明确类型清理。未知装修差异保留并报告。

灯具造型参考 [故宫六方挂灯](https://www.dpm.org.cn/light/368370.html)，贴图和静态模型为项目原创，不打包馆藏图片。

## 本轮实测结果

- 最终构建与 60 项 Forge GameTest 全部通过，含栏杆直线、T 形、连接实心柱、拆除联动、墙体保护及修缮日志合并回退状态检查。日志：`qa/watercourt-final3-tests.log`。
- 独立原生客户端读取实际世界：58 处登记建筑结构差异为 0；17,466 个池底/护岸点、4,417 个源水点、592 个栏杆点和 49 处上岸口检查通过。此项是登记结构核对，不代表每间屋内所有装饰均已人工验收。
- 生存模式分别从商铺步道、西侧云阁、云阁北侧水中出发，只按前进，关闭跳跃与冲刺，三次均到达干燥岸面，`onGround=true`、`flying=false`。测试发现并修复了原先最上一级缺少半步过渡的问题。记录：`qa/watercourt-swim-probes.json`。
- 新步道增加 12 盏嵌地白玉灯，避免夜间昏暗和地面立灯占路；保留栏杆上岸开口。
- 与修缮前副本比较，主城 185 个、宗门 298 个方块实体无删除和内容变化；玩家/商铺/住宅数据与宗门记录保持一致。
- 重跑日志保留 61 处自然地表变化（60 处草方块退化为泥土、1 处泥土长草），位置表：`qa/watercourt-preserved-differences.json`。这些不属于建筑缺块，不强制覆盖。
- JAR 中无原版 `assets/minecraft/` 材质覆盖；栏杆使用原版方块标签实现联动。客户端 ZIP 约 2.9 MB，官方第三方组件另下载约 16 MB，附哈希校验。

### 交付状态与未完成验收

成品 JAR：`mod/build/libs/duskrain-2.2.0-preview.jar`。轻量客户端包：`dist/DuskRain-2.2.0-preview-candidate5-client-mods.zip`。

更新旧客户端时先关闭游戏，备份并移出旧 DuskRain JAR，再安装本包；同名旧版本的哈希不同，安装脚本会拒绝直接覆盖。服务端也必须使用同一构建，再执行维护命令。

本轮修缮已应用于独立验收世界 `mod/run-watercourt-r6/saves/DuskRainRemake`，原 PCL 实例和公网服务器尚未迁移；没有发布 GitHub Release。完整原生回退演练、三档性能压测和全楼层逐间人工验收仍未完成，不能据此声称整个重制项目全部验收通过。
