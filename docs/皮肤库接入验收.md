# 百衣藏皮肤库接入验收

验证日期：2026-09-16。披风扩展同日追加，当前以本文“披风扩展”记录和新版操作说明为准。线上入口：[百衣藏](https://skin.duskrain.cn/library/)。

## 交付范围

- LittleSkin 公共皮肤库：关键词、经典／纤细模型、人气／时间筛选、分页、3D 预览、来源及上传者、应用到自己的角色。
- Mojang Java 正版皮肤：玩家名与 UUID 查询、模型识别、复制当前皮肤、跟随后续外观。
- 衣冠阁首页、导航和角色页入口；中文使用说明、部署配置和扩展后的备份脚本。
- 继续使用 Drasl 4.0.1 的账号、UUID、登录验证和上传接口；不增加新的账户数据库或前端管理令牌。

## 披风扩展实测

同日补齐首版遗漏的 `cape` 分类和 Mojang `CAPE` 字段；以独立临时账号验证，原测试角色不参与外观变更。

| 场景 | 结果 |
|---|---|
| 社区披风 | 浏览、3D 披风渲染、翻至第 2 页和网页应用通过；存储 PNG 与原站逐字节一致，原细臂皮肤 URL 和 slim 模型保持。 |
| 正版披风 | 查询 jeb_ 的公开档案，读取当前 `CAPE`；“只换披风”保留原细臂皮肤，披风 PNG 与官方一致。 |
| 整套复制 | 同一次网页提交应用 `skinFile` 与 `capeFile`，两份 PNG 与官方一致，模型正确。 |
| 整套跟随 | 页面明确选择后清除本地两项材质，保留本站 UUID；服务端返回同时含 `SKIN` 和 `CAPE` 的正版签名资料。 |
| 跟随转混搭 | 先跟随带披风的正版角色，再分别单换社区披风、单换社区皮肤；两种方向都把另一项当前外观保存到本站，模型及 PNG 正确。 |
| 没有披风 | 查询 Notch，显示“当前未公开穿戴披风”，披风单换及整套复制选项禁用，皮肤仍可应用。 |
| 仅有披风 | 衣柜仍渲染 3D 披风；不显示空皮肤图片。 |
| 游戏原生校验 | Java 17 + Minecraft 1.20.1 authlib 4.0.43 + authlib-injector 1.2.8，secure textures API 接受正版皮肤和披风；登录、join/hasJoined、角色 UUID 和签名密钥通过。 |
| 窄屏与回归 | 390×844 的披风列表与弹窗无横向溢出，桌面 1440×1000 可正常操作；19 项原认证回归检查再次通过。 |

静态入口增加资源版本参数，角色页主题也更新版本，避免浏览器缓存旧脚本或样式。此轮仍是网页与游戏原生库验证，未声称完成图形游戏客户端多人披风观感验收。机器结果见本地 `docs/qa/cape-tests.json`、`cape-native-textures.txt` 与 Playwright 截图。

## 后端兼容性说明

Drasl 4.0.1 仅当角色没有本地皮肤和披风时转发正版整套外观。新版单独应用会保留另一项：本地已有的材质不改动，来自跟随的材质保存当前 PNG 以便混搭。用户明确选择“跟随整套外观”后才清除两项本地材质；约 10 分钟缓存，客户端也可能缓存，不承诺即时刷新。

跟随返回原 Mojang 签名的材质属性，其内部来源 UUID 可以是正版角色 UUID；外层游戏角色 UUID 仍为本站原 UUID。已通过 Minecraft secure textures API 验证，不把材质来源误当成角色身份迁移。

仅启用 `ForwardSkins`，明确关闭 fallback 的 `EnableAuthentication`，保留 `SignPublicKeys=true`。这次更新不开放 Mojang 与本站账号混合登录。

## 保存与回退

部署前已完成数据库在线一致性备份，另保存原站配置、Nginx 虚拟主机及模板；部署后备份加入静态皮肤库和新代理配置。Nginx 配置检查通过，代理 TLS 验证保持开启。数据库、签名私钥、令牌、密码和测试账号资料均不纳入 Git。

回退可以移除域名虚拟主机中的皮肤库 include，并恢复原模板；校验 Nginx 后重载、重启皮肤站容器。已应用的皮肤保存在本站，保留数据库和皮肤文件即可；不要为回退页面覆盖玩家数据库。需要停用正版跟随时另行处理 fallback 配置，避免影响正在使用该功能的玩家。

测试临时账号已删除，原账号 UUID 已复核；10 个实际部署的代码、模板与配置文件和本地源文件 SHA-256 一致。机器检查结果和截图存于本地 `docs/qa/`、`output/playwright/`；公开仓库保留本摘要及匿名皮肤库网页截图。来源、版本和许可见 [组件与署名](../deploy/skin-station/THIRD_PARTY.md)。
