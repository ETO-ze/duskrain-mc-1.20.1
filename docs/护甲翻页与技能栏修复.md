# 护甲翻页、右下技能条与指南更新

2026-09-15；Minecraft 1.20.1 / Forge 47.4.10；DuskRain 协议仍为 5，指南版本 14。

## 本次修复

- 器阁翻页按钮的筛选参数包含冒号，原指令参数在冒号处截断。改为受校验的引号字符串，完整传递页码和筛选。
- 目录每页最多 8 件。点击底部“上页 / 下页”切换页码，小窗口滚轮查看本页其余商品。支持法器 / 法衣、境界、部位筛选；商品详情返回原目录。
- Z / X / C 状态移至右下角，宽窗口横排，较窄窗口竖排；极窄窗口避开原版生存状态栏。侧栏为技能条留出间距。
- F9 同时切换左上信息、右侧栏和技能条的卷轴 / 半透明样式；偏好保存到客户端配置。
- 更新 45 页新手手册。背包、副手、末影箱内的旧指南自动原位升级；个人书籍不修改。缺失时 `/dr guide` 补领。
