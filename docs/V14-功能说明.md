# V14 新功能与迁移说明

## 铭灵与登神

铭灵轩在玄岩器阁旁，云篆提供剑鸣、通玄、镇岳、聚灵、归元、护心、踏云、御风八种附魔。原版附魔台、铁砧和砂轮仍可使用；专属附魔不进入随机附魔池。每件最多三个专属词条。原版附魔与绑定数据保留。

目标等级k的费用为200k²灵石、4k青金石、k灵纹砂、2k经验等级，阶段至少3(k−1)。灵纹砂由四个紫水晶碎片、四个青金石和一张纸合成两个。升级必成，一次一级，满级不再扣款。必须在柜台距离内操作。

原18阶段编号不变，新增登神初、中、后期（Lv.19–21）。飞升须完成24项主线，首次消耗60000修为、3劫雷灵核、1下界之星；后续为120000/240000修为、6/12神纹晶、2/4下界之星。突破费用只在挑战成功时结算。雷台问劫出劫雷灵核，登神后的对应可重复挑战出神纹晶。

神境额外生命为160/260/400，伤害倍率2.5/3.5/5，灵力300/600/1000，各阶段不累加。PVP仅保留神境新增量的20%，生命上限切换保持比例。高生命使用数值血条。原玩家不会自动突破，也不会再次加灵石。

## 御剑

剑修金丹初期永久解锁，其他流派登神后解锁；换流派重新判断。云渡使出售500灵石/10分钟、2000灵石/60分钟体验。落地、离线暂停租期。R起剑/缓降，WASD移动，空格上升，Shift下降。普通10格/秒，登神14格/秒，上下5格/秒，默认每秒2灵力，御风降低消耗。

主城、生存世界及本人洞天可用；新手区、擂台和试炼关闭。战斗及结束后15秒不能起飞，受伤、耗尽或到期缓降。碰撞与宗门隔离仍由服务器检查，未加载区域停止前进。下线、死亡和换维度清理实体。

收剑卡视角的修复：Shift只表达飞行下降意图，不再取消服务端同步的正常下马事件。真实客户端已验证Shift降落和R收剑后转向、步行。

## 府邸与商铺

中文宗名支持2–16个汉字、字母、数字或下划线；创建/转让要求至少渡劫后期。原编号1保留成员、权限与位置，名称为合欢宗，224×224府邸分块建设一次，完成后不自动重刷。

新增铭灵轩的基础会查实际存档地面，避免新高度计算与旧地形不一致造成悬空。宗门溪水改为低位有岸水渠，曲桥两端连接岸上，转角围栏让出三格通道，水边花草检查落脚方块。

小集每铺27种商品，每种最多4096件。铺主从真实背包选择物品，设置每件单价、数量；可补货、改价、部分取回。物品、耐久、附魔、自定义名称与全部NBT相同时才可补入同一商品。绑定法器不能寄售。旧商品继续整组旧价出售，并标记旧批次。

交易使用服务端库存版本、请求编号和落盘恢复记录；陈列格不能拖走库存，铺主离线仍可收款。断线与重复提交不会按客户端给出的余额或物品结算。
