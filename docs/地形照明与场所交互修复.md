# 地形、照明与场所交互修复

## 本轮依据

用户提供的两张游戏截图显示了问道书院旁的台基落差、路面和草地之间的空隙，以及殿内深处的暗区。源代码检查进一步确认：旧道路仅在每隔六格补路柱，支路与主路独立拉坡，旧通行检查没有比较相邻采样点的高差。

## 设计与实现

- **道路与地形：**按原始山岛地形做局部整地，使用建筑地基、道路和边坡范围作为蒙版。道路外过渡 6–9 格再接回山坡，范围以外保留原始地形。路下连续补齐路基，路口共享平台高度；石砖路面增加地灯。
- **建筑：**台基补齐连续基础，告示牌有实心底座；主入口依然连接公共步行路线。每层增加分布式灯笼、地面海晶灯与楼梯侧灯。检查真实方块光照，不用白天日照代替夜间照明。
- **浮岛廊桥：**原创深木桥面、青瓦顶、桥头亭、桥侧弧形梁架与栏杆灯光。步行面保留五格净宽，桥顶与行走空间分开。
- **植物稳定：**试炼竹子以苔藓块作为有效基底，设置成熟阶段；庭院竹子同样补齐种植床。测试会主动触发邻居变化，再等待计划更新，检查整株是否保留、是否产生竹子掉落物。
- **真实商人：**客户端放行已登记村民的右键，服务端识别稳定 UUID 和服务标签。柜台入口与村民共用校验和交易逻辑。每位商人只提供自己的商品，不能远程打开其他商店。
- **独立商店页：**使用专门的柜台界面，展示当前店铺、余额、商品、数量和翻页；不包含全局商店切换导航。
- **G 菜单：**保留人物、技能、任务追踪、签到、住宅、队伍、出行和显示设置。商店在对应村民处打开；拜师/突破在问道书院办理；任务奖励在任务殿交付；试炼在问劫云台开启。命令保留，但场所限制同时在服务端执行。
- **传送：**起点和终点有青玉色法阵、升起的粒子与音效；回城引导期间播放旋转法阵，仍遵守移动/受伤取消和战斗冷却。
- **迁移：**替换主城维度前备份存档，保留生存世界与 UUID 玩家进度。旧主城中的玩家首次进入此版本时移至安全出生点，保留现有任务计数。

## 参考资料

- [Minecraft：地形与景观教程](https://www.minecraft.net/en-us/article/tutorial--tips-for-landscaping-and-terraforming)：道路顺应地形，并使用边墙、宽度变化处理景观过渡。
- [WorldEdit 7.2：区域操作](https://worldedit.enginehub.org/en/7.2.20/usage/regions/regionops/)：局部平滑、自然表土分层的工作方式。本项目使用自己的地形蒙版与存档生成步骤，没有把安装 WorldEdit 当作修复完成。
- [UNESCO：中国木拱桥传统营造技艺](https://ich.unesco.org/en/RL/traditional-design-and-practices-for-building-chinese-wooden-arch-bridges-02156)：木构、桥屋与梁架的设计参考；桥体与方块组合均为本项目原创。
