# 2.2.0-preview：实施与验收

状态：2.2 体验版；2026-09-25 已核验公网服加载协议 8。最新交付与边界见 [发行检查](releases/2.2.0-preview.md) 和 [更新日志](../CHANGELOG.md)。以下日期记录保留历史状态。

## 发行范围

按玩家的新要求，公开下载仅面向客户端。不含服务端、世界、玩家、Java、游戏本体、录屏和源码副本。自研 JAR 配合锁定的官方源下载器；第三方 JAR 不在 GitHub 再分发。少量客户端初始配置用于地图位置、HUD、皮肤和按键兼容；已存在的个人配置不由安装器覆盖。

锁文件中的 SHA-1/SHA-512 来自 Modrinth，SHA-256 为官方哈希校验通过后本地计算。只有 `python tools/sync-modrinth-dependencies.py --update` 能更新锁定版本；普通构建不追新。原有光影栈固定版本，FastSuite/Placebo、声音 Beta、3D Skin Layers 为可选；Visual r3 起光影包默认安装。

## 地图与技能 HUD

- JourneyMap 6.0.5 对应 Forge 1.20.1。左上小地图替代行旅录，J 打开全屏地图、F8 收展；无 JourneyMap 时保留原行旅录。
- 主城提供 16 个公共楼阁/服务点标记；不包含玩家住宅或其他宗门的全局坐标。临时标记切换维度时清理。
- 宅地轮廓只使用服务端原来已发送的附近边界，保留自己青色、成员金色、他人红色；超时清除。
- 不显示其他玩家雷达；服务器预设关闭远程玩家定位、洞穴图及地图传送，试炼关闭地图。
- Z/X/C 改为 26×20 的三个小格，常规横排总宽 84 GUI 像素，原为 194。显示实际绑定键、冷却数字/锁图标；就绪用短线表示。小窗口自动竖排；F9 仍控制透明风格。
- Jade 接管指向对象说明，避免重复叠加 DuskRain 的目标信息框。JourneyMap 默认 G 键冲突只在首次迁移解除，之后保留玩家修改。
