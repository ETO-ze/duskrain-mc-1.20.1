## 地图根因和修补

基线检查发现 1,073 个积水或阻挡的道路采样点；铭灵轩路段有 8 处树叶阻挡；东侧道路穿过 14 号民居的基础。南侧宗门服务建筑与部分商铺低于海平面，直接清水后会被重新灌入。

修补内容：

- 非桥梁路面至少高于当地水面一格，坡度仍限制为每水平格最多升降一格。
- 宗务堂、两座宗门传送阁和低洼商铺抬高；临水路段加石砌护岸、栏杆和灯。
- 东侧主街由 x=109 移至 x=115，接回支路；修复 14 号民居被道路切掉的基础。
- 按真实存档补足道路下方支撑；重新安放受影响路灯，清理铭灵轩通路树叶。
- 商铺入口平台延长，补齐抬高后转角处的边缘。
- 新生成区块在景观之后再落实通路，避免后续树叶盖掉道路。

## 正式服升级步骤

必须先停服并备份正式服当前世界和配置，再将客户端、服务端同时更新为该 JAR。不能将测试世界覆盖正式服。

在维护窗口用控制台或 OP3 执行一次：

```text
dr admin site_repair
dr admin site_detail
dr admin walk_audit
dr admin route_audit
dr admin fixture_audit
dr admin site_audit
```

`site_repair` 是显式公共建筑修补，不在登录或每次开服时自动执行。它会重建指定公共建筑与商铺陈设；若将改动装有实物的实体容器，会在修改前中止并报告坐标。商铺寄售库存和所有权属于独立持久化数据，修补不改这些数据。不要在玩家施工时反复执行。

修补先写 `duskrain-city-repair-时间戳.json` 方块差异日志，再修改方块并保存。完整世界备份仍是恢复依据；该日志不是包含全部实体 NBT 的备份。批量修补会短暂占用服务器线程，本次本地一次出现约 3.6 秒延迟，应该在维护窗口执行。
