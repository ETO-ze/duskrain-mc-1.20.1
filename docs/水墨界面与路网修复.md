# DuskRain · 水墨界面与路网修复

Minecraft Java 1.20.1 / Forge 47.4.10 / Java 17，群号 205255670。

## 本轮内容

- 侧栏改用原创宣纸卷轴、淡墨山形、朱红雨字印和回纹边饰；左上角为“行旅录”，显示 FPS、延迟和坐标。F8 隐藏信息 HUD，G → 显示设置调整侧栏与光影。
- 瞄准方块显示名称，瞄准生物显示生命；登记商人显示对应地点与交互提示。界面菜单打开时隐藏外部 HUD，避免信息叠在商店旁边。
- Tab 由服务端提供玩家境界、流派、延迟，以及在线人数、群号、个人区域、PVP、灵石和灵力。单人预览受原版单人 Tab 显示条件限制，专用多人服务器正常使用 Tab。
- 材料、丹药、法器村民分别打开独立商店。背包、余额、境界、数量和六格内实际距离由服务端检查。离开商人后，旧页面不能继续交易。
- G 保留个人成长、任务追踪、队伍、住宅、出行和显示设置；商店、拜师、突破、任务交付和试炼启动在对应村民处办理。
- 原创 32× 材质覆盖 13 张青瓦、木构、白玉和灯具贴图。主体仍使用原版方块，不改变配方和掉落。
- 内置 FerriteCore 6.0.1，客户端和服务端均可加载。保留 Embeddium 0.3.31、Oculus 1.8.0、GeckoLib 4.8.4 和 Complementary Reimagined r5.3。

## 地形和建筑

采用局部地形高度蒙版、表土分层和连续基础，使道路与建筑周围地形衔接。外围自然山岛不整体铲平。室内补充真实光源，所有检查均读取方块光照，未用光影亮度代替。

本轮路网 v9 补上山门后方的南北主路、传送阁前连接，以及试炼桥通往中央道路的入口。九处浮空桥转角改为共用平台，7×7 转弯范围保持通畅；柱子、围栏和灯具放在外围。桥面、青瓦廊顶、弧形木梁与桥头亭统一使用深木青瓦。

竹子改在有效苔藓基底上种植，使用成熟阶段，主动触发邻居与计划更新后保持 72 节竹竿，无竹子掉落物。原有告示牌修复仍会同时补发方块和文字 NBT，并在存档读取时恢复登记牌文。

## 服务器内置材质

`server/resourcepacks/DuskRain-Jade-City.zip` 随包交付。正常启动脚本同时启动仅提供此 ZIP 的 HTTP 服务，计算 SHA1 并更新 `server.properties`。关闭 Minecraft 服务端时同步停止该辅助服务。`-CheckHost` 可只检查材质服务后退出。

`server/resourcepack-host.json` 默认仅服务本机：

```json
{"bindAddress":"127.0.0.1","port":25567,"publicBaseUrl":"http://127.0.0.1:25567"}
```

局域网或公网开服时，将 `publicBaseUrl` 改成玩家可访问的 HTTP/HTTPS 地址，并配置对应监听、转发或反向代理。127.0.0.1 只供本机测试，不能让远程玩家下载。此项与 Minecraft 游戏端口分别配置。
