## 告示牌修复

1. 服务端拦截受保护告示牌的左键破坏，并保留现有方块实体。
2. 依次发送方块状态、包含正反两面文字的方块实体数据。
3. 在 2 tick 和 8 tick 后再次同步，覆盖客户端预测破坏和恢复的时序。
4. 新版主城中已变成空白、且能与设计坐标对应的牌子，在区块加载或再次交互时从设计数据恢复。
5. 重新施工写入文字后发送更新并标记保存。生成牌统一写入双面文字、发光和涂蜡状态。

已有非空的管理员自定义文字不会被设计文本覆盖；维护模式下允许的真实拆除仍按维护权限处理。

实现依据：Forge 区分方块状态与方块实体数据，动态文字需要后者同步并标记保存。见 [Forge 1.20.1 方块实体文档](https://docs.minecraftforge.net/en/1.20.1/blockentities/)。本轮验证了服务端真实破坏路径与数据包内容；尚未在停止桌面控制后重新进行客户端视觉复现。

## 如何体验

本项目开发环境：运行 `tools/start-preview.ps1`，进入单人存档 **DuskRainRemake**。脚本使用项目内独立 Java 17。主菜单按 G，主动技能默认 Z/X/C。

主城分区使用 `/dr warp`。测试管理员也可用以下命令到新增景观建筑门前：

```text
/execute in duskrain:city run tp @s -177.5 129 -131.5
/execute in duskrain:city run tp @s 196.5 66 198.5
/execute in duskrain:city run tp @s -221.5 67 183.5
```

观察告示牌时使用非维护模式的普通玩家。管理员 `/dr admin maintenance` 是切换命令，聊天提示会显示当前是否开启。
