# DuskRain 2.2 客户端使用说明

适用：Minecraft Java **1.20.1 / Forge 47.4.10 / Java 17**，DuskRain **2.2.0-preview，协议 8**。

## 最快安装：PCL2 导入包

1. 从 [v2.2.0-preview Release](https://github.com/ETO-ze/duskrain-mc-1.20.1/releases/tag/v2.2.0-preview) 下载 **DuskRain-2.2.0-PCL2-Visual-r3.mrpack**。这是推荐下载；无需同时下载 ZIP。
2. 将文件拖入 PCL2，或选择“下载 → 整合包 → 安装已有整合包”。使用新的独立版本名称，不覆盖其他整合包。
3. 等待启动器下载原版、Forge、15 个第三方客户端模组和 **Complementary Reimagined r5.3 光影**。文件从官方源获取并校验；包小是因为使用下载清单，并非完全离线安装包。
4. 在版本设置确认 **Java 17**。有 8 GB 系统内存可先分配约 3 GB，16 GB 及以上可从 4 GB 起步，按实际内存余量调整。
5. 在 [衣冠阁](https://skin.duskrain.cn/web/registration) 注册并建立游戏角色。PCL2 版本内已经预设外置登录站，使用自己的皮肤站账号密码登录。若启动器未读取预设，手动添加：`https://skin.duskrain.cn/authlib-injector`。
6. 启动游戏，点击 DuskRain 首页“启程”，或在多人游戏添加 **nbc.rainplay.cn:42741**。交流群：**205255670**。

包内不提供共享账号、密码、会话或其他玩家信息。不要使用离线登录连接此服务器。

## 画面内容已经如何交付

| 内容 | 安装方式 |
|---|---|
| 原创中式建筑、法衣、法器、NPC 模型和材质 | 内置 `duskrain-2.2.0-preview.jar`，无需额外下载材质包 |
| 建筑法线与反光材质 | 同样内置自研模组；配合光影显示凹凸和反光 |
| Oculus、Embeddium、动态光源等 | 启动器按清单自动下载锁定版本 |
| Complementary Reimagined r5.3 | 本版为默认安装内容，自动下载到 `shaderpacks`，不再需要额外勾选 |
| 三档画质 | 默认启用“轻岚 · 流畅”，另外两档在游戏里切换 |
| JourneyMap / Jade / JEI | 默认安装；提供地图、指向说明和物品配方查询 |
| 3D Skin Layers / Sound Physics | 仍为可选项，不属于入服必需内容；见下方 ZIP 安装方法 |

原创建筑贴图位于 `duskrain` 命名空间，主城、宗门共用。**生存世界的原版方块仍用原版贴图**；全局光影照明会影响所有支持的维度。旧版 `DuskRain-Jade-City.zip` 曾覆盖原版材质，不应重新启用；本版自研模组会取消选择这个旧资源包，但不删除文件或玩家其他资源包。

**光影作者：EminGT / Complementary Development。** [官方主页](https://www.complementary.dev/) · [锁定版本 r5.3](https://modrinth.com/shader/complementary-reimagined/version/71Hn3myZ)。光影没有修改，DuskRain 仅提供外部参数预设；整合后的兼容性问题由 DuskRain 项目维护方负责。更多署名和许可见 [第三方组件](第三方模组与许可证.md)。

### 切换画质

按 **G → 显示设置** 打开“烟雨画境”。新实例默认界面尺寸为 2，避免小窗口使用过大的自动缩放；原版视频设置中可以自行调整。

| 档位 | 参考设备 / 分辨率 | 设置取向 |
|---|---|---|
| 轻岚 · 流畅（默认） | RTX 2060 / 1080p | 10 区块视距，法线材质，关闭视差凹凸 |
| 烟雨 · 均衡 | RTX 4060 / 1080p | 14 区块视距，近景视差凹凸与反光 |
| 云阙 · 精致 | RTX 5070 / 1440p | 20 区块视距，更精细视差与彩色灯光 |

显卡名称只是配置参考，不代表这些型号都完成了实机跑分。切换时需要编译光影，可能短暂停顿；可选“关闭光影”或“恢复上次设置”。旧实例通过 ZIP 更新时不会覆盖已有画质文件，需在此页面主动选一档。

## 常用操作

| 操作 | 功能 |
|---|---|
| G | 主菜单：修炼、任务、商店、领地、宗门、队伍、试炼等入口 |
| J / F8 | 全屏地图 / 收起或显示小地图 |
| Z / X / C | 三个职业主动技能；右下角小格显示冷却或解锁状态 |
| F9 | 切换卷轴与轻量 HUD |
| R / 空格 / Shift | 御剑起落 / 上升 / 下降，需要资格或体验时间 |
| `/dr guide` | 补领或更新完整入世指南 |
| `/dr spawn` / `/dr warp` | 引导回城 / 分区传送；战斗时受限制 |

详细玩法和全部指令见 [入世手册](https://github.com/ETO-ze/duskrain-mc-1.20.1/blob/main/docs/入世手册.md)、[中文指令手册](https://github.com/ETO-ze/duskrain-mc-1.20.1/blob/main/docs/中文指令手册.md)。按键可在原版控制设置里调整；JourneyMap 首次打开有官方介绍页，关闭后进入地图。

## 备用 ZIP：已有 Forge 实例

下载同一 Release 的 **DuskRain-2.2.0-client-Visual-r3.zip**，解压到一个临时文件夹。关闭游戏，备份原实例，执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\install-client-mods.ps1 -GameDirectory "E:\.minecraft\versions\你的独立实例"
```

脚本默认安装光影，下载时校验 SHA-512、SHA-256 和大小。它会保留已有配置，遇到同名但内容不同或重复版本的模组会停止；先将旧版移至实例外备份，再运行。不要把 ZIP 中的 `defaults` 目录直接当成模组放进 `mods`。

可选增加角色皮肤立体层和声音效果：

```powershell
powershell -ExecutionPolicy Bypass -File .\install-client-mods.ps1 -GameDirectory "实例完整路径" -SkinLayers -Sound
```

可选组件不在本次默认组合验收范围。安装器不会删除你的个人模组，但无法保证任意第三方整合包兼容，优先使用新建实例。

## 常见问题

- **无效会话：**关闭游戏，在启动器退出并重新登录衣冠阁账号，然后重新启动。不要反复使用已经运行的旧游戏会话。
- **FML 模组不兼容 / 协议不一致：**确认使用本次客户端，不能混用 2.1（协议 7）与 2.2（协议 8）；保留一份 DuskRain JAR。服务端也必须完成对应更新。
- **没有光影 / 提示组件不齐：**检查启动器下载任务是否完成，以及实例 `shaderpacks/ComplementaryReimagined_r5.3.zip` 是否存在，再到 G → 显示设置选档。网络失败时重试官方源下载，勿只复制自研 JAR。
- **只有原版方块外观：**生存世界原版方块保持原版是预期行为。中式模型用于自定义建筑方块；光影关闭后仍有模型与基础纹理，但没有光影的反光、视差效果。
- **启动黑屏、显存不足或卡顿：**先关闭光影。无法进菜单时，关闭游戏后将实例 `config/oculus.properties` 中的 `enableShaders` 改为 `false`，重新启动。
- **地图挡住菜单 / 字太大：**使用 F8 暂时收起小地图，在原版“视频设置 → 界面尺寸”调整缩放；本版默认小地图左上，技能栏位于右下。

## 更新边界

Release 只交付客户端及安装说明，不含服务端、世界、Java 和账号。进入公网服看到的地图由服务端提供，重新导入客户端不会重建地图。当前旧世界迁移仍有保留冲突记录，未宣称逐栋修缮全部完成，也未完成本版 20 名真人长期压测；详见 [更新日志](https://github.com/ETO-ze/duskrain-mc-1.20.1/blob/main/CHANGELOG.md)。
