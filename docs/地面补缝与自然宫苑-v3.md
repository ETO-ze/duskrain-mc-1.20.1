# 地面补缝与自然宫苑 v3

> 本文保留该阶段的历史测试结果与本机记录路径。2026-09-25 公网迁移及最新交付状态以 [2.2 发行检查](releases/2.2.0-preview.md) 为准。

本轮仅更新独立本地测试副本，未迁移公网服或正式 PCL 实例。版本仍为 Minecraft 1.20.1 / Forge 47.4.10 / Java 17，协议 8 未变。

## 修正范围

- 12 间商铺的两侧巷道、门前平台及临水步道；青灰砖与白玉边带衔接，半格高差过渡，铺地以下连续基础。
- 宗务堂及两座云阁的完整台基，填实墙脚、柱础、告示牌基座和栏杆之间的空槽。原告示牌、容器、服务对象不移动。
- 外岸约 16 格内的自然宫苑：曲径、花境、竹丛、乔木、置石和三处小型休憩节点。
- 补齐护岸与园路之间的窄槽；扩大斜向岸边登记，避免距离计算漏掉斜坡碎石沟。水庭源水、荷叶、莲灯和上岸口保留。
- 独立地面检查覆盖通路宽度、头顶空间、地基、岸边种植区、护栏和装饰，不能只靠建筑蓝图一致性宣布通过。

## 数据与回退边界

v1 / v2 修缮记录保留，新施工写入 v3。执行前比较当前方块与记录，只在批准的范围内施工，所有方块实体均跳过。39 处草块 / 泥土差异保留，详见 `qa/courtyard-v3-skips.json`。

回退副本演练：41,458 个日志位置中，静态建筑恢复；213 处差异为流动水自然重算（200 处水变空气、13 处空气变水）。因此不能把命令回退称为逐方块完全相同。要求水流、计划刻和整个世界完全回到原时刻时，退出游戏后从完整备份恢复，不能用在线修缮日志代替整存档备份。

完整备份：`backups/courtyard-v3-20260924/world`。原始体验存档及每次测试副本均保留。
