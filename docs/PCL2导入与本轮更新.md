# DuskRain 客户端导入与服务器更新 · 2026-09-25

## 玩家安装

1. 打开 PCL2，将 `DuskRain-2.2.0-PCL2-20260925-r2.mrpack` 拖入窗口；也可以使用“下载 → 整合包 → 安装已有整合包”。
2. 使用独立的新版本名称安装，避免覆盖其他整合包。启动器安装 Minecraft 1.20.1、Forge 47.4.10，并按锁定网址下载客户端组件。
3. 本包约 2.94 MB，只内置 DuskRain 模组、配置和下载清单；首次安装仍需要下载原版运行文件、Forge 和第三方模组。这不是完全离线包。
4. Java 范围固定为 `[17.0,18.0)`，不捆绑 Java。如果启动器找不到 Java 17，请先安装。
5. 使用“DuskRain 衣冠阁”外置登录。注册地址 `https://skin.duskrain.cn/web/registration`，验证地址 `https://skin.duskrain.cn/authlib-injector`。账号、密码和会话不包含在包内。
6. 启动后显示 DuskRain 水墨首页，点击“启程”进入 `nbc.rainplay.cn:42741`。无效会话时先退出游戏，在启动器重新登录；协议不匹配时确认服务器与客户端已经同步更新。

地图默认左上角，J 打开大地图，F8 隐藏小地图；G 主菜单，F9 侧栏，Z/X/C 技能，R 御剑。保留单人世界、服务器列表、设置和退出入口。

旧实例默认配置不会自动覆盖个人设置。本轮已备份并将 `mod/run-courtyard-v3e` 两套现存地图位置改为 `TopLeft`，其他偏好保持不变。

## 服务器迁移

暂存目录：`/server/duskrain-update-courtyard-20260925`。

面板启动命令必须为：

```sh
sh /workspace/start-duskrain.sh
```

启动脚本先校验文件，冷备份世界、模组、配置和认证 JVM 参数，再安装协议 8 的模组。冷备份路径：`/backup/duskrain-courtyard-20260925/server-before.tar.gz`。现有外置认证、端口、UUID、住宅及商铺数据保留，没有上传或替换整片公网世界。

显式请求文件 `duskrain-architecture-v3.request` 启动增量修缮；进度和原方块记录写入世界内 `duskrain-architecture-v3`。完成后请求改名为 `.applied`，之后开服不会自动重复重建。中断后按进度续作；冲突方块和方块实体保留并报告。
