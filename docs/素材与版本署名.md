# DuskRain 素材与版本署名

本轮地图地形、建筑、植被布局、装饰模型、首领模型贴图、界面与修仙代码由本项目原创制作。主体建筑使用原版方块；模型中的原版材质路径引用由 Minecraft 提供。

## 设计参考

- V14府邸：[故宫歇山顶资料](https://www.dpm.org.cn/lemmas/241941.html)；衣装：[馆藏云纹袍](https://www.dpm.org.cn/collection/embroider/228698.html)。只参考形制和纹样组织，未打包馆藏图片。
- V14原创资源：84件法衣、21件立体法器、11位服务NPC；生成源 `tools/generate_v14_art.py`，512px人物与法衣UV重新绘制。玩家原皮肤不替换。

- 故宫博物院：[慈宁宫花园](https://gugongzhanlan.dpm.org.cn/exhibitShare/11)。用于了解松柏、花木、水池和亭阁的组合；未复制展品图片或模型。
- KingTheQueen：[Avatar 地形候选](https://www.planetminecraft.com/project/avatar-the-last-airbender-world-1-19/)。下载未取得，未使用该地图或附带树木素材。

## 本轮原创与动态光源

- 青瓦白玉立体材质：21组64×原创颜色、法线/高度、反光/发光贴图，共63张。CC0-1.0。生成源见 `tools/generate_pbr.py`。
- [LabPBR 1.3格式说明](https://shaderlabs.org/wiki/LabPBR_Material_Standard)。仅参考通道标准，未复制第三方贴图。
- 十八阶段法衣、七位人形居民皮肤：原创，源见 `tools/generate_outfits.py`。NPC底层仍使用村民服务行为，显示为自制人形模型。
- [Sodium/Embeddium Dynamic Lights Forge 1.20.1 1.0.10](https://modrinth.com/mod/sodium-dynamic-lights/version/I156ee3A)，toni / LambdAurora，MIT。原包内部版本字段为1.0.9，锁定以发行ID与文件SHA-512为准。
- [Sodium Options API Forge 1.20.1 1.0.10](https://modrinth.com/mod/sodium-options-api/version/d0EFLitO)，toni，LGPL-3.0-only。

动态光源两项仅加入客户端；未修改上游JAR，原始许可和发行元数据随包保留。
